# "Clean checkout" means: no $ROMDIR, no decrypted views under build/out/,
# no build directories. That is what CI has, and it is the whole reason this
# list is shorter than "the ROM-free gates" — a gate that SKIPs for want of
# build/out/vsavj_opcodes.bin is not portable, it is silent.
#
# THE JOB MUST FAIL ON SKIP. A CI job named "tests" that runs 3% of them and
# reports green is its own false green; one that runs 12 and says so is
# honest. The runner asserts each line below exits 0 AND does not print SKIP.
#
# Kept beside the gates, not in the workflow file, so adding a gate is a
# one-line edit here rather than a change to executable CI config.
