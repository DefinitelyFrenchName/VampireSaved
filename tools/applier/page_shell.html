    What every byte is checked against. Each of your files is verified member by member before anything is built; the rebuilt parts are verified again against this release's own fingerprints; and the finished set's identity is checked against what this release declares. If any of that does not match, you get the name of the thing that is wrong and no file at all — the same rule the command-line applier follows.
