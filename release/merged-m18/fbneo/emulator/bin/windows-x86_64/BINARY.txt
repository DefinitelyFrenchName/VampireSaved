requires   Windows 10 or later, x86_64. Nothing to install: the DLLs the recipe links from MSYS2 (SDL2 (sdl2-compat over SDL3 where the host uses it), SDL2_image and their image codecs) sit beside the .exe, where the loader looks first. Keep the folder together.
run        run it from a directory that has a `roms/` subdirectory holding your built vsavjw.zip AND your pristine vsav.zip (FBNeo has no rom-path option: it reads `roms/` relative to the current directory, or the paths set in its config): `./fbneo.exe vsavjw`. Controls: FBNeo's own menu (Tab).
